# Cubic Bezier sketch profiles

Choose Sketch → Spline · Bézier. One profile contains a single cubic Bezier edge and a straight chord joining its endpoints. P0/P3 are endpoints; P1/P2 are control handles, not points the curve must pass through. Enter their X/Z coordinates in millimetres and choose Create profile, or pick the four controls in order with pen/mouse. Touch remains available for navigation and selection. A successful construction selects the exact closed region for extrusion.

The tool displays pending control markers and a control polygon. While picking the fourth point, it samples a live curve preview. These display helpers never enter CAD geometry or exports. Completed curves are not edited by changing the next-construction inputs. General NURBS, multiple spline spans, interpolation through arbitrary fit points, automatic tangent constraints and dragging completed handles are not implemented by this stage.

`spline-tool.mjs` validates four finite controls within ±1,000,000 mm. Endpoints must be separated by at least 0.01 mm and endpoint tangents must be nonzero. The controls must lie on the same side of the closing chord, and the profile must enclose positive area. A normalized polynomial test rejects self-intersections and interior singular tangents. Invalid text does not replace the last valid saved settings. The kernel repeats validation before constructing an analytic OCCT Bezier edge and planar face. Samples are used solely for previews; canonical B-Reps preserve the exact curve through region splitting, signed extrusion, holes, Booleans, point inspection and STEP.

Creation stages the returned face before a single history commit. Cancelling a pointer commits no control; switching tools while the worker is busy invalidates its result. Three pending controls are retained until the fourth produces a valid profile, so an invalid final pick can be corrected. Undo Point removes a pending control. Extrusion of another selected region clears pending controls consistently with other sketch drafts; Undo restores the prior draft.

Version 5 files optionally store `splineTool: {points: [{x,y}, ...]}` with four controls for the next construction; y means sketch Z. Older documents use the default 60 mm wide, 30 mm high control polygon. A pending draft has tool `spline` and an optional `splinePoints` list of at most three controls. Completed profiles use the existing canonical face B-Rep format. Files, Undo/Redo and local recovery preserve both settings and pending controls. Loading invalid settings/drafts rejects the file before replacing the current document. File/recovery data does not restore camera state.

`tests/spline.test.cjs` independently checks Bernstein coordinates, affine area, analytic derivatives/curvature, Simpson-integrated arc lengths, signed extrusion, STEP, circular holes, overlap integrals and exact Boolean volumes. Invalid and self-intersecting profiles must not poison later operations. Protected shipping tests in Chromium/WebKit exercise numeric inputs, point reports, touch selection, holes, drafts/history/recovery, real pen-type input (Chromium), pointer cancellation and late replies. Windows CI runs the Chromium workflow. Physical iPad/Pencil/OS Files acceptance remains #6.
