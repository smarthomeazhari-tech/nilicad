# Exact ellipse sketch

Choose Sketch → Ellipse. Numeric construction accepts semi-axis X and Z (not full diameters), rotation in degrees and center X/Z in millimetres. Either semi-axis may be larger. Create ellipse commits one exact closed region and selects it for extrusion. Pen/mouse dragging from center to a bounding corner, or two picks at those points, creates an axis-aligned ellipse; numeric construction supports rotation. Each semi-axis must be 0.01–10000 mm. The whole ellipse must fit within ±1,000,000 mm sketch coordinates.

`ellipse-tool.mjs` validates settings and builds sampled display previews only. `browser-engine/kernel.mjs` constructs an analytic OCCT ellipse edge with explicit major-axis direction and assembles its planar face. Equal semi-axes are accepted. Reversed axis sizes rotate the OCCT major direction by 90 degrees. Canonical face B-Reps carry exact geometry into region splitting, point inspection, signed extrusion, Booleans and STEP. Display meshes and previews never become the exact curve.

Construction stages and validates the returned region before the current document changes. Errors, cancelled pointer gestures and late worker replies after switching tools leave document geometry intact. Existing completed profiles are preserved. Canonical B-Rep profiles participate in every requested region split, including overlaps between newly created exact ellipses; they are not assumed to be an already independent arrangement.

Version 5 projects optionally store `ellipseTool: {rx, ry, angle, center: {x, y}}`, where center.y means sketch Z. This configures the next construction, not a parametric edit of a completed profile. Older files default to 25/15 mm semi-axes. A pending center uses `sketchDraft.tool = "ellipse"` and `rectStart`. Settings and drafts survive files, history and local recovery; completed regions use the existing canonical B-Rep format.

Geometry tests independently check area, signed volume, ellipse equations, overlapping/nested region area, point curvature and STEP round trips. Protected shipping tests cover numeric input, invalid files, Undo/Redo, point inspection, touch selection, holes, canonical overlap extrusion, local recovery, mouse/pen construction, pointer cancellation and late-reply cancellation in Chromium/WebKit. Windows CI runs Chromium. Physical iPad/Pencil/OS Files acceptance remains issue #6. General splines, constraints and arbitrary sketch planes remain outside this stage.
